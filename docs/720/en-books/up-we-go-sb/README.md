# Up We Go — Student's Book · בסיס ידע פנימי

תיקייה זו היא **בסיס הידע הקבוע** של הצוות על ספר הלימוד `Up We Go Student's Book`,
לצורך פיתוח תוכן אנגלית לתוכנית 720.

המטרה: לאפשר עבודת תוכן, עיצוב פדגוגי, כתיבת יחידות והפקת מדיה **בלי לפתוח שוב את קובץ ה-PDF המקורי**.

## סטטוס הכיסוי

| טווח | מה זה | מצב |
| --- | --- | --- |
| עמ' 10–24 | Unit 1 — "Send a Message!" (Section 1 · Smartphone Teens) | מחולץ ומתומלל |
| עמ' 25 | `My Vocabulary File` — עמוד הסיכום של היחידה | **מחוץ לטווח שנמסר**. ראו הערה למטה |
| שאר הספר (228 עמ') | — | לא חולץ |

> **פער ידוע:** תוכן העניינים של הספר מציין שיחידה 1 משתרעת על עמ' **10–25**.
> הטווח שנמסר למשימה (10–24) מכסה את כל היחידה **למעט** עמוד סיכום אוצר המילים (עמ' 25).
> ההחלטה אם לכלול את המקבילה הפדגוגית של עמוד זה בלומדה מתקבלת בשלב העיצוב הפדגוגי.

## מבנה התיקייה

```
up-we-go-sb/
├── README.md              ← הקובץ הזה: מפת התיקייה וכללי השימוש
├── BOOK-PROFILE.md        ← פרופיל הספר: הוצאה, גיל, CEFR, אנטומיית יחידה, רובריקות, סוגי תרגילים, טון
├── PAGES-010-024.md       ← תמלול נאמן עמוד-אחר-עמוד של עמ' 10–24, כולל תיאור מילולי של כל איור
├── assets/                ← p010.png … p024.png — צילום מלא של כל עמוד ב-160dpi
└── raw-text/              ← p010.txt … p024.txt — הטקסט הגולמי כפי ש-PyMuPDF חילץ אותו
```

## מקור ואופן החילוץ

- קובץ מקור: `docs/720-en-books/Up We Go SB.pdf` (228 עמודים).
- כלי החילוץ: `backend/scripts/extract_book_pages.py` (dev-only, דורש `pymupdf` בסביבה זמנית).
- היסט עמודים: **0** — מספר העמוד המודפס זהה למספר העמוד ב-PDF. הסקריפט מאמת זאת מול מספר העמוד בכותרת התחתונה ונכשל בקול רם אם ההיסט שגוי.

שחזור החילוץ:

```bash
python3 -m venv /tmp/pdfenv && /tmp/pdfenv/bin/pip install pymupdf
/tmp/pdfenv/bin/python backend/scripts/extract_book_pages.py \
  --pdf "docs/720-en-books/Up We Go SB.pdf" \
  --out docs/720/en-books/up-we-go-sb \
  --first 10 --last 24
```

## כללי שימוש

1. **`PAGES-010-024.md` הוא המקור הסמכותי לטקסט.** הטקסט ב-`raw-text/` גולמי: סדר הקריאה מעורבב בין עמודות, והגלוסות בעברית ובערבית מגיעות לעיתים עם אותיות הפוכות או תווים חסרים. אין להעתיק ממנו ישירות.
2. **`assets/` הוא המקור הסמכותי לפריסה ולאיורים.** בכל מקום שבו התמלול והתמונה נחלקים — התמונה מנצחת.
3. **זהו חומר עבודה פנימי בלבד.** הלומדה שנבנה **אינה משכפלת** את עמודי הספר ואינה מציגה את התמונות שלהם. הספר משמש כמקור להיקף, לרצף ולרמה הלשונית; התוכן הנראה ללומד נכתב מחדש ומקורי.
4. גלוסות בעברית ובערבית בתמלול נשמרות כי הן מלמדות איזו מילה הספר מחשיב כקשה ללומד הישראלי — מידע ישיר לתכנון התמיכה הלשונית בלומדה.
