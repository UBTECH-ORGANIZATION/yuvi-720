# משימות התלמיד

בעוד מסלול הלמידה מונע מהמלצות המערכת, המשימות מגיעות מהמורה. הן מופיעות לתלמיד במסך נפרד.

## רשימת המשימות

![רשימת המשימות של התלמיד](../screenshots/student-tasks/01-list.png)

הרשימה מסודרת לפי מועד ההגשה ומצב המשימה. משימה שהוגשה נשארת ברשימה לצפייה.

## פתרון משימה

![מסך פתרון משימה](../screenshots/student-tasks/02-solve.png)

גם כאן הממשק מצטמצם לטובת ריכוז. המשימה מוצגת פריט אחר פריט, והתקדמות נשמרת תוך כדי — תלמיד שיצא באמצע יחזור לנקודה שבה עצר.

התלמיד מקבל משוב מילולי לאורך הפתרון. המשוב מנוסח בשפה מכוונת-למידה ואינו מציג ציון מספרי.

> **למדריך:** משימה שאינה מופיעה אצל תלמיד — בדקו במסך המשימות של המורה שהמשימה אכן שוגרה ולא נשארה כטיוטה. ראו פרק "יצירת משימות ומעקב אחריהן".
